# car_ver0 —— STM32F103C8T6 蓝牙双电机小车（WASD 单字符遥控 + 三档 PWM）

基于 **STM32CubeMX 6.15.0**（STM32Cube FW_F1 V1.8.7）生成的 **MDK-ARM（Keil 5）** 工程。

> 命令解析、运动逻辑、函数封装、参数与设计巧思的详细说明见 **[代码解析.md](代码解析.md)**。

硬件与之前相同：STM32F103C8T6 + JDY-31 + L298N + 两个 1:30 减速电机 + 3S 锂电池/LM2596。
本版只改软件：蓝牙命令改为 **w/a/s/d 单字符遥控**，并增加 **z/x/c 三档 PWM 调速**。

## 1. 命令表

| 按键 | 动作 | 蓝牙回传 |
| ---- | ---- | -------- |
| `w` | 前进：左右两轮正转 | `FWD` |
| `s` | 后退：左右两轮反转 | `BACK` |
| `a` | 左转约 **10°**：**停车时原地转；行进中边前进/后退边差速左转，不打断行驶** | `LEFT` |
| `d` | 右转约 **10°**：**停车时原地转；行进中边前进/后退边差速右转，不打断行驶** | `RIGHT` |
| `z` | 一档速度：PWM 占空比 **65%** | `SPEED 65%` |
| `x` | 二档速度：PWM 占空比 **80%** | `SPEED 80%` |
| `c` | 三档速度：PWM 占空比 **98%** | `SPEED 98%` |
| `q` | 停车 | `STOP` |
| `n` / `f` | 板载 LED 开 / 关（**f 熄灭 LED 的同时停车**） | `LED ON` / `LED OFF` |

说明：

- **单字符命令**，发送后立即执行，不需要回车；大写 `W/A/S/D/Z/X/C` 同样识别。
- 回车、换行、空格等非命令字符会被忽略，不会误动作。
- 上电默认速度为一档 **65%**；行驶中发送 `z/x/c` 会**立即**改变当前速度，停车时发送则记录档位、下次行驶生效。
- 三个速度档位对应 TIM3 的 CCR：65% → 2340，80% → 2880，98% → 3528（ARR=3599，20 kHz）。
- `q` 是停车键；`f` 熄灭 LED 时也会同时停车，`n` 只点亮 LED、不影响电机。
- `a`/`d` 是**定角转向**：停车时两履带反向原地转 10° 后停车；**行进中不会打断前进/后退**，只让内履带短暂降速，转完自动恢复两履带同速继续行驶。

### 2.4 关键注意点

1. **L298N 的 ENA、ENB 两个跳线帽都必须拔掉**，否则 PWM 无效、只能全速。
2. **电池 11.1 V 直接接 L298N +12V**，不要经过 LM2596。
3. **共地**：电池负极、L298N GND、LM2596 GND、STM32 GND 必须接在一起。
4. 右电机默认按镜像安装处理（`MOTOR_B_INVERT = 1`）。若按 `w` 后小车原地打转：
   - 把 [main.c](Core/Src/main.c) 中的 `MOTOR_B_INVERT` 改为 `0`，**或**
   - 对调右电机接 L298N 的 M+/M− 两根线（两种方法只用一个）。
5. LM2596 先空载调到 **5.0 V** 再接负载；不要同时用 USB 和 5V 脚给 Blue Pill 供电。
6. 3S 锂电池不要放电低于 9.0 V，建议加低压报警/保护板，用平衡充电器。

## 3. 软件实现

命令全部为单字符，所以接收端不再组帧，直接在中断里识别字符，主循环用 `switch` 执行：

```c
/* 中断：只接收有效字符 */
if ((c == 'w') || (c == 'a') || (c == 's') || (c == 'd') ||
    (c == 'z') || (c == 'x') || (c == 'c') ||
    (c == 'q') || (c == 'n') || (c == 'f'))
{
  key_char  = c;
  key_ready = 1U;
}

/* 主循环：转向时间到 */
if ((turning != 0U) && ((int32_t)(HAL_GetTick() - turn_end_tick) >= 0))
{
  if (car_dir == 0U)
  {
    Car_Stop();                     /* 原地转向结束 */
  }
  else
  {
    turning = 0U;
    Motor_SetSpeed(speed_percent);  /* 行进中转向结束：恢复直行，继续前进/后退 */
  }
}

switch (key_char)
{
  case 'w': Car_Forward();  break;   /* 两轮正转 */
  case 's': Car_Backward(); break;   /* 两轮反转 */
  case 'a': Car_Turn('a'); break;    /* 停车原地转 / 行进中差速左转 */
  case 'd': Car_Turn('d'); break;    /* 停车原地转 / 行进中差速右转 */
  case 'z': Car_SetSpeedLevel(65U); break;
  case 'x': Car_SetSpeedLevel(80U); break;
  case 'c': Car_SetSpeedLevel(98U); break;
  case 'q': Car_Stop();     break;
  case 'n': LED_On();       break;
  case 'f': LED_Off(); Car_Stop(); break;   /* 灭灯并停车 */
  default: break;
}
```

- `speed_percent` 保存当前档位；`car_moving` 标记是否在行驶，`car_dir` 记录 0=停/1=前进/2=后退。
- 行驶中改档：`Car_SetSpeedLevel()` 会立刻重写 CCR1/CCR2，电机速度实时变化；行进转向中改档会保持差速不变、外履带跟随新档。

### 3.1 10° 转向方案：线速度 × 延时（开环），不用 PID

选择**开环定时**而不是 PID，原因：

- 10° 是小角度定位；PID 需要编码器反馈、每转脉冲数、轮径、履带中心距和参数整定。本工程此前的编码器 A/B 相并没有接线，为 10° 增加完整闭环的成本和风险都不划算。
- 转向命令是“按一次转 10°”的离散动作，用固定占空比 + 固定时间即可满足演示/课程要求，逻辑简单、可预测。
- 后续若把编码器接上（PB6/PB7、PB8/PB9 等），可以很容易改为计数闭环。

转向分两种情况，互不影响：

**① 停车时按 a/d：原地差速转**

```
两履带反向，65% 占空比
履带中心距 B ≈ 245 − 33 = 212 mm，驱动轮直径 D = 39 mm
电机 1:30，333 r/min（12 V 空载），65% 下有效转速约 165 r/min
v = π × 0.039 × 165 / 60 ≈ 0.337 m/s
ω = 2v / B ≈ 3.18 rad/s ≈ 182 °/s
10° 理论 ≈ 55 ms，加起步死区/滑移取 TURN_PIVOT_MS = 100 ms
```

**② 前进/后退中按 a/d：边跑边转（不打断行驶）**

```
外履带 = min(当前档位 + TURN_OUTER_BOOST, 100)，内履带 = 外履带 − TURN_INNER_DROP
65 档：外 80 / 内 50
80 档：外 95 / 内 65
98 档：外 100 / 内 70

差速仍为 30 个点：
Δv ≈ 30 × 0.00518 ≈ 0.156 m/s
ω = Δv / B ≈ 0.156 / 0.212 ≈ 0.733 rad/s ≈ 42 °/s
10° 时间 ≈ 10 / 42 ≈ 0.238 s → TURN_MOVING_MS = 240 ms
```

**为什么两履带要整体抬高？**

旧版本是“外履带保持档位、内履带降 30 点”，65 档时内履带只有 **35%**。履带阻力较大时，35% 可能低于某一侧电机的起转阈值：这一侧作为内履带时会被拖着走、甚至停转，于是出现“一个方向转向正常、另一个方向特别慢”的现象。现在把两履带整体抬高 15 个点（内履带 50%、外履带 80%），差速仍是 30 点，但内履带不会再因占空比过低而停转；同时 65/80 档的平均速度仍约为 65/80，行进不会明显减速。

内/外履带的选择与 a/d 的转向方向保持一致：

- `a`（原右转逻辑）：前进时内履带在右，后退时内履带在左；
- `d`（原左转逻辑）：前进时内履带在左，后退时内履带在右。

转向过程中**不改变方向引脚、不调用 `Motor_SetSpeed(0)`**，时间到后自动恢复两履带同速，继续原来的前进/后退。

关键参数：

| 宏 | 默认值 | 含义 |
| -- | ------ | ---- |
| `TURN_DUTY_PERCENT` | 65% | 原地转向占空比 |
| `TURN_PIVOT_MS` | 100 ms | 原地转 10° 的时间 |
| `TURN_INNER_DROP` | 30 | 行进转向时内履带比外履带低的点数 |
| `TURN_OUTER_BOOST` | 15 | 行进转向时两履带整体抬高的点数 |
| `TURN_MOVING_MS` | 240 ms | 行进中转 10° 的时间 |

标定方法：

1. **原地**：发一次 `a`，量实际角度 θ，按 `TURN_PIVOT_MS × 10 / θ` 调整；
2. **行进中**：先发 `w` 前进，再发 `a`，量实际角度 θ，按 `TURN_MOVING_MS × 10 / θ` 调整；
3. 如果某一侧转向仍明显偏慢，说明该侧履带张紧度/电机阻力更大：可适当提高 `TURN_OUTER_BOOST`（整体更有力），或检查履带松紧、电机接线。

## 7. 常见问题

- **发送字符没反应**：确认串口助手工作在 **9600 8N1**、发送的是单字符（不是 `w\r\n` 也没关系，换行会被忽略），并检查 JDY-31 的 TX/RX 是否交叉、是否共地。
- **w 前进时原地打转**：右电机方向反了，改 `MOTOR_B_INVERT` 或对调右电机两根线。
- **调速没变化**：确认已发送 `z/x/c`；行驶中改档立即生效，停车时改档只记录，需再发 `w/s` 才体现。
- **小车只能全速**：L298N 的 ENA/ENB 跳线帽没拔。
- **转向角度偏大/偏小**：停车原地转向调 `TURN_PIVOT_MS`，行进中转向调 `TURN_MOVING_MS`，都按 `新值 = 当前值 × 10° / 实测角度` 缩放。
- **a/d 转向方向反了**：原地转向方向由 `Car_Turn()` 里 a/d 两支的 `Motor_SetLeft/Right` 决定；行进中由 `turn_inner_left` 决定，把 `Car_Turn()` 中 a/d 的内履带选择对调即可。
- **行进中按 a/d 车停了**：正常逻辑不应停车，行进转向只调用 `Car_ApplyTurnSpeeds()`，不碰方向脚；检查是否误加了 `Car_Stop()`。
- **停车原地转向后自动停**：正常，`car_dir==0` 时 100 ms 后自动 `Car_Stop()`。
- **跑偏**：两电机开环转速有差异，本版无编码器闭环，可后续加入 PID。
- **蓝牙连不上**：JDY-31 是经典蓝牙 SPP，需安卓 SPP 串口助手；苹果通常不支持。
- **Keil 中文注释乱码**：`Edit → Configuration → Editor → Encoding` 选择 **UTF-8**。
